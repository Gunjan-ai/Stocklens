# AI Stock Insight Assistant
Streamlit + OpenAI + yfinance

- # StockLens — AI-Powered Stock Analysis Dashboard

> Ask questions about any stock in plain English. Get real-time charts, 
> technical indicators, and AI-generated buy/sell insights instantly.

## 🚀 Live Demo
[Try it on Streamlit →](https://gunjan-ai-stocklens-app-s3daxl.streamlit.app/)

## 🎯 What it does
- Fetches real-time data for Indian (NSE) and US stocks
- Displays price trends, EMAs, RSI, MACD and key indicators
- Uses OpenAI GPT to generate plain-English analysis and recommendation
- Works for any stock: Reliance, TCS, Infosys, Apple, Tesla, etc.

## 🛠 Tech Stack
Python · Streamlit · OpenAI API · yfinance · Pandas · Plotly
